# newsletter-assets

Public image hosting for the Highlands Chamber of Commerce community newsletter.

Each issue has a folder named for its send date (for example `2026-11-19/`) holding the
header and event title images. The HTML email loads them from
`https://visithighlandsnc.github.io/newsletter-assets/<date>/<file>.png`.

**Never delete or rename old folders.** Sent emails and the Mailchimp archive keep loading
their images from here.
